## 0) HOW THIS FILE WORKS

Each cluster = one or more pages. For every page we define:
- **Primary keyword** (the main rank target)
- **Secondary / long-tail** (supporting keywords on same page)
- **Intent** (what the searcher wants)
- **Title tag** + **H1** + **URL slug**
- **AI-answer block** = the 40-60 word direct answer to place in the FIRST 200 words (this is what AI engines quote)

> RULE OF THUMB (2026 AI search): the first 200 words must DIRECTLY answer the query. Self-contained 200-400 word passages with a number/stat get cited most.

## 8) AEO / GEO CHECKLIST (rank in AI Overview + ChatGPT + Claude + Perplexity + Gemini)

- [ ] **Direct answer in first 200 words** — 40-60 word self-contained answer (up to +115% citation likelihood).
- [ ] **Include a number/stat** in that answer (stats = +30-40% AI visibility).
- [ ] **"Last updated: <date>" visible** on data pages — refresh ≥ every 30 days (3.2x more citations). Our cron does this daily automatically = huge edge.

- [ ] **Tables** for data (AI parses tables cleanly).
- [ ] **Cite the source** (NSE) with a link — named sources get quoted more.
- [ ] **Cross-link** — gainers → stock page → FII holding (internal entity graph).
