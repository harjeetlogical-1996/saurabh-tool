# Reviews Hub — Complete Ranking Roadmap

## Where the site stands
On-page SEO is already excellent (top 10% of sites): full schema, voice/AI/GEO optimization,
internal links, sitemap, fast, mobile, fresh dates, reviews, E-E-A-T authors, 25 articles.
Ranking now depends mostly on OFF-PAGE factors + going live.

---

## PHASE 1 — GO LIVE (without this, ranking = 0)  [CRITICAL]
Google cannot see a local site. Nothing ranks until this is done.
1. Buy a domain (e.g. on Namecheap/GoDaddy) + hosting (Hostinger/Cloudways/SiteGround).
2. Deploy: Local by WP Engine has "Connect to Host" / export, OR migrate via plugin
   (All-in-One WP Migration / Duplicator). Dates, reviews, schema all carry over.
3. Set up SSL (https), set permalinks, confirm site loads live.
4. Install a caching plugin (WP Rocket / W3 Total Cache) for speed.

## PHASE 2 — GET INDEXED  [CRITICAL, week 1 after live]
5. Google Search Console: add property, verify, submit /wp-sitemap.xml.
6. Bing Webmaster Tools: same (Bing + ChatGPT use Bing index).
7. Request indexing for top pages.
8. Google Analytics 4: install for traffic tracking.

## PHASE 3 — BACKLINKS (the #1 off-page ranking factor)  [ongoing]
Backlinks = other sites linking to you = "votes" Google trusts. A new site needs these.
Free/white-hat methods:
- Business listings/citations: Google Business, niche directories.
- Guest posts on powersports/outdoor blogs (write for them, link back).
- Help-a-reporter (HARO / Connectively): answer journalist queries, get cited.
- Reddit/forums/Quora: genuinely helpful answers that link where relevant.
- Create "linkable assets": the Store Finder tool + comparison data are link-worthy.
- Digital PR: a small data study ("we compared 100 stores...") that blogs cite.
Paid (use carefully): niche edits / guest-post placements from reputable sites.
AVOID: link farms, PBNs, fiverr bulk links (Google penalty).

## PHASE 4 — CONTENT DEPTH (topical authority)  [ongoing]
9. Grow from 25 -> 40-60 articles (more subcategories, "X vs Y", buying guides).
10. Update old articles periodically (Google rewards freshness).
11. Build content clusters: each category pillar links to all its sub-guides and back.

## PHASE 5 — ON-PAGE BOOSTERS  [DOING NOW - possible on local]
- Related guides section under each article (internal links, dwell time).
- Stronger contextual internal linking between related articles.
- Author profile pages (E-E-A-T authority).
- Organization + logo schema (brand entity).
- Per-article Open Graph images for social shares.
- Breadcrumbs everywhere.

## Realistic timeline
- New site takes 3-6 months to start ranking even with everything right ("sandbox").
- Easy-win long-tail keywords rank first; competitive head terms take longer + backlinks.
- Consistency (publishing + backlinks over months) is what wins.
